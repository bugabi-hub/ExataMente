# ExataMente
## O que é esse projeto?
ExataMente é um site desenvolvido pelo CodePen com o objetivo de ajudar alunos com dificuldade em matemática, contribuindo para o fortalecimento da aprendizagem na área de Ciências Exatas.

## Objetivo
Oferecer uma avaliação diagnóstica que permita aos estudantes verificar seu desempenho em Matemática e identificar seus erros.

## Como funciona?
- O estudante responde uma avaliação com questões de matemática
- Ao final recebe seu resultado e a porcentagem de aproveitamento
- Pode revisar as questões e consultar as explicações das respostas.

## Ferramentas Utilizadas
- CodePen 
- HTML 
- CSS 
- JavaScript
