# ExataMente
ExataMente é um site criado pela ferramenta do CodePen com o objetivo de ajudar alunos com dificuldade em matemática quais áreas devem ser revisadas.

## Canvas
### Problema
Atualmente, devido à problemas de aprendizagem e dificuldades psicológicas, muitos alunos tem dificuldades na área de exatas.

## Ferramentas Utilizadas
-CodePen
-HTML
-CSS
-JavaScript

### Título Médio (Para os subtópicos)

2. Destaques no texto (Negrito e Itálico) Querem chamar a atenção para uma
palavra importante? Usem o asterisco *:
Markdown
Para deixar a palavra em **negrito**, coloque dois asteriscos em volta dela.
Para deixar a palavra em *itálico*, coloque apenas um asterisco de cada lado.

3. Listas (Para organizar as tecnologias e ferramentas) Para fazer aquelas listas
com bolinhas, é só colocar um traço - (ou um asterisco *) e dar um espaço:
Markdown
Ferramentas que usamos:
- Python

- GitHub
